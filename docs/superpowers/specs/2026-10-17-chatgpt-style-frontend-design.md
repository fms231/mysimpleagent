# ChatGPT 风格前端页面设计

## 目标

将现有对话页调整为简洁、熟悉的 ChatGPT 式界面，同时保留现有会话及对话能力。

## 界面方案

- 使用浅色主题和低对比度的中性色。
- 左侧显示固定宽度的会话栏，包含品牌、新建会话和历史会话列表。
- 主聊天区占据剩余空间，消息内容居中并限制最大宽度。
- 用户消息使用浅灰圆角背景；助手消息以简洁文本呈现。
- 输入框固定在主区底部附近，居中显示，采用圆角容器。
- 窄屏时隐藏侧栏，聊天区使用可用宽度。

## 行为与边界

保留当前前端的会话加载、新建会话、发送消息、编辑用户消息、工具调用与结果展示及后端 API 交互。此项改动聚焦 HTML/CSS 呈现，不改变接口和消息处理逻辑。
